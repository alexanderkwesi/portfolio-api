# Portfolio API

A backend API project for serving structured portfolio/project data through HTTP endpoints.

## Why I Built It

I built this project to practise separating frontend presentation from backend service logic. The aim was to expose portfolio-style information through a simple API and demonstrate route design, JSON responses and backend fundamentals.

## Features

- Express backend service
- JSON-style API responses
- Route-based backend structure
- Simple frontend entry point for testing or presentation
- Node package scripts for local development

## Tech Stack

- Node.js
- Express
- JavaScript
- Vite
- HTML

## Project Structure

```text
backend/       Backend API code
index.html     Frontend entry point
package.json   Project scripts and dependencies
README.md
```

## Getting Started

Install dependencies:

```bash
npm install
```

Run the backend:

```bash
npm run start-backend
```

Run the frontend/dev workflow:

```bash
npm run dev
```

## What This Shows

This repo demonstrates backend fundamentals: route structure, service separation, JSON responses and practical API development.
